# Assets

Ce dossier regroupe tous les fichiers utilises par le site.

## Dossiers

- `images/` : photos, illustrations, visuels de sections
- `logos/` : logos SFLM, partenaires, marques
- `icons/` : icones SVG ou PNG
- `videos/` : videos courtes, fonds video, demonstrations
- `fonts/` : polices locales si necessaire
- `documents/` : PDF, plaquettes, fichiers telechargeables
