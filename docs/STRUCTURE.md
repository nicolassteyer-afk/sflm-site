# Structure du site SFLM

## Racine

- `index.html` : page principale du site
- `styles.css` : styles globaux
- `script.js` : interactions legeres
- `vercel.json` : configuration Vercel

## Assets

- `assets/images/` : photos, illustrations et bannieres
- `assets/logos/` : logos et variantes
- `assets/icons/` : icones SVG ou PNG
- `assets/videos/` : videos du site
- `assets/fonts/` : polices locales
- `assets/documents/` : PDF et documents telechargeables

## Content

- `content/pages/` : textes de pages
- `content/data/` : donnees reutilisables

## Docs

- `docs/` : notes projet, brief, charte, idees et suivi
